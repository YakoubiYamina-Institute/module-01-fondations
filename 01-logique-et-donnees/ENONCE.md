# Semaine 1 : La Récolte de la Donnée (Logique & Vérité)

## 🎯 Objectif Technique
Créer un algorithme simple (en Python) qui vérifie la cohérence d'une donnée entrée par l'utilisateur.

## 📝 Spécifications
1.  Le programme doit demander : "Quel est votre âge ?"
2.  Il doit vérifier si l'âge est logique (compris entre 0 et 120).
3.  **Si l'âge est invalide** (< 0 ou > 120) : Afficher "Erreur : Cette donnée semble fausse. La vérité est une obligation."
4.  **Si l'âge est valide** : Afficher "Donnée vérifiée. Merci pour votre honnêteté."

## 🤲 Dimension Éthique (Le Métrologue)
*Vérité (Sidq) :* Une donnée entrée fausse donne un résultat faux (Garbage In, Garbage Out).
**Réflexion :** Pourquoi est-il dangereux pour une application bancaire ou médicale d'accepter des données fausses ? Écrivez 2 lignes dans votre fiche `MESURE.md`.

## 📂 Livrable
- Un fichier `main.py` contenant votre code.
- Une fiche `MESURE.md` remplie (copiez le modèle depuis `ressources/templates/`).
