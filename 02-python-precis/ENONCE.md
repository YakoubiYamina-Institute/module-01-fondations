# Semaine 2 : La Mesure du Langage (Python Core)

## 🎯 Objectif Technique
Apprendre la syntaxe exacte de Python. Écrire un script qui calcule la moyenne d'une série de notes.

## 📝 Spécifications
1.  Définir une liste de notes (ex: `[12, 15, 8, 18]`).
2.  Calculer la somme et la moyenne.
3.  Gérer le cas où la liste est vide (pour éviter l'erreur de division par zéro).
4.  Afficher le résultat avec précision.

## 🤲 Dimension Éthique (L'Économie / Juste Milieu)
*Éviter le gaspillage :* Écrire un code efficace qui ne consomme pas plus de ressources (CPU/Mémoire) que nécessaire.
**Réflexion :** Comment éviter d'écrire des lignes de code inutiles ou des boucles infinies qui gaspillent l'énergie ?

## 📂 Livrable
- Un fichier `moyenne.py`.
- Une fiche `MESURE.md` remplie.
