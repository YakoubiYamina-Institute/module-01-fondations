# Semaine 3 : L'Ordre et la Structure (Structures de Données)

## 🎯 Objectif Technique
Organiser des données pour les retrouver et les utiliser justement. Créer un petit annuaire.

## 📝 Spécifications
1.  Utiliser un **Dictionnaire** Python pour stocker des noms et des numéros de téléphone.
2.  Ajouter 3 contacts.
3.  Créer une fonction pour rechercher un contact par son nom.
4.  Si le contact n'existe pas, afficher un message clair (pas d'erreur brute).

## 🤲 Dimension Éthique (L'Organisation / Ihsan)
*Clarté :* Un code bien structuré est respectueux envers ceux qui le liront après vous. C'est une forme de bienfaisance (Ihsan).
**Réflexion :** Comment un code "spaghetti" (désordonné) peut-il nuire à la maintenance future et à la sécurité ?

## 📂 Livrable
- Un fichier `annuaire.py`.
- Une fiche `MESURE.md` remplie.
