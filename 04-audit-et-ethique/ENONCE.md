# Semaine 4 : L'Audit et la Protection (Sécurité & Versionnement)

## 🎯 Objectif Technique
Protéger son travail, assurer sa traçabilité et nettoyer son code.

## 📝 Spécifications
1.  Reprendre le code de la Semaine 1 ou 2.
2.  Ajouter des **commentaires** expliquant le "POURQUOI" du code (pas juste le comment).
3.  Vérifier qu'aucun mot de passe ou clé API n'est présent dans le code.
4.  Faire un commit Git propre avec un message explicite.

## 🤲 Dimension Éthique (L'Amanah / Responsabilité)
*Responsabilité :* Assumer chaque ligne de code commitée. Le versionnement est une preuve de transparence.
**Réflexion :** Pourquoi est-il malhonnête de committer du code avec des messages comme "fix" ou "update" sans détails ?

## 📂 Livrable
- Le code amélioré et commenté.
- Une fiche `MESURE.md` remplie (avec une réflexion sur la responsabilité).
- Une capture d'écran de votre historique Git propre.
