## 🎯 Mission du Module
Ce module pilote vise à établir la **Juste Mesure** dans l'apprentissage du développement. Il ne s'agit pas seulement d'apprendre à coder, mais d'apprendre à coder avec **intention (Niyyah)**, **précision** et **responsabilité**.

Nous appliquons ici la rigueur du métrologue :
- Chaque variable est une donnée mesurée.
- Chaque fonction est un processus vérifié.
- Chaque algorithme est une balance équitable.

## 🤲 Méthodologie : La Fiche de Mesure
Chaque exercice doit être accompagné d'une fiche `MESURE.md` remplie par l'étudiant, incluant :
1.  **Niyyah** (Intention)
2.  **Vérité des données**
3.  **Économie de ressources (Green Code)**
4.  **Impact Éthique**

👉 Voir le modèle : [ressources/templates/MESURE.md](ressources/templates/MESURE.md)

---

## 🚀 Comment commencer ?
1.  Clonez ce dépôt.
2.  Lisez le fichier `ENONCE.md` dans le dossier de la Semaine 1.
3.  Codez votre solution.
4.  Remplissez votre `MESURE.md`.
5.  Soumettez votre travail !
